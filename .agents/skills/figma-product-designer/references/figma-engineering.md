# Figma 工程与可靠绘制

## 范围与连接

- 先读取所用工具的当前 schema；不要猜参数或把历史工具行为视为当前事实。
- 多文件连接时明确路由。用户禁止读取现有画面时，只查询必要连接信息，不遍历页面、组件或选择内容。
- 同时使用组件创建 skill 时，禁止读取既有内容的约束同样覆盖组件盘点、样式/变量扫描和页面边界检查。只验证本次新建组件及实例；默认组件与 Visual Guide 放在本次交付容器的独立区域。不为满足辅助 skill 的通用盘点步骤突破用户授权。
- 未获准覆盖时只追加自己的交付容器。无空白区域定位能力时说明选定位置未经碰撞验证，不能把远坐标称为保证空闲。
- 不主动改动插件运行时代码来完成设计任务。

## 原生结构

推荐层级：交付容器 → 页面/状态 → 内容区块 → 组件实例 → 内容。组件区与设计注释区独立。

- 纵向页面内容采用垂直 Auto Layout；工具栏、字段组、行项目采用合适的水平布局或换行规则。
- Hug 用于由内容决定的标签、按钮或区块高度；Fill 用于可用空间分配；Fixed 用于明确的画板、图标或受控列宽。必须确认父容器支持所选行为。
- 宽度受约束的文本自动增高；不可把全页文本都设置为固定高度。
- 卡片高度跟随内容。长原因换行；需要省略的次要标识必须有查看完整内容的路径。
- 建立稳定重复项的组件；变化通过适当的文本、布尔、实例替换属性和少量变体表达。不要为每个文案值创建变体。
- 用户允许读取现有体系时优先复用；禁止读取时创建自包含体系，不声称与原文件已有组件一致。
- 区分统一的原始视觉值与 Figma 原生 style/variable 绑定。无读取授权时不扫描全文件 token，也不为补齐绑定擅自创建变量；交付明确未绑定，不能把相同 HEX/字体值说成已完成设计系统接入。
- 使用语义命名：Page/Overview、Section/Connection、Button/Primary、State/Error。避免无意义编号和 Frame 123。
- 无原生布局或组件写入能力时明确结构交付限制，不用扁平矩形集合冒充组件系统。

## 字体与文本预检

先验证目标字体/字重和中英文覆盖，使用可用文字测量接口。以一个小节点验证宽度、自动增高、实际返回尺寸及截图。

历史操作曾出现工具文档支持 width-only、运行时却只在 width 与 height 同时存在时 resize 的情况。这是兼容性风险，不是永久假设。若实际复现，采用经过验证的显式尺寸与文本自动增高组合，并报告不一致；禁止静默接受零宽度。

## 批量与恢复

- 优先使用已有声明式场景/布局工具，按当前 schema 执行预检或 dry-run。批量调用负责减少往返，不代替布局设计。
- 场景预检若拒绝某个布局组合，不反复提交同一无效方案，也不声称 dry-run 已通过。可按当前工具支持拆为小步创建与原生布局设置，再以实际尺寸变化确认约束；不以固定坐标降级冒充 Fill。将预检与实际设置之间的能力差异列入交付限制。
- 保存根节点、创建引用和步骤状态。批次大小受操作上限、响应体积与执行时间共同约束，不盲目填满最大数量。
- 仅在工具明确支持时使用 compact 回执；输出太大则缩小后续批次、采用浅查询或独立读取细节。
- 解析失败或客户端超时不代表写入失败。确认原调用已结束，再仅查询本次已知根节点/节点 ID；有按本次 operationId 限定的状态接口时才读取对应操作，不直接重放。禁止读取既有内容时，不调用返回整个 session 历史或无法限定作用域的 journal，即使它的名称看似用于恢复。调用外层超时应覆盖实际长写入，避免主动中断正常执行。
- 查询优先 ID、名称、边界和浅层摘要，不为获取一个 ID 请求整棵树。
- atomic 的实际回滚范围以工具文档为准；不能假设对现有节点的所有修改都会恢复。

## 验证与产物

- 对本次根节点运行可用布局检查；区分实际裁切、字框交叠和有意叠放。再读截图确认，不能只信诊断数量。
- 测试内容增高、容器变窄、组件属性变化是否保留布局。另画窄屏不能代替尺寸变化实验。
- 截图按工具允许的产物目录导出；不要默认可写 /tmp。使用唯一文件名，不覆盖已存在文件。
- 深链接、选中节点和缩放视口只在工具确有能力且操作范围明确时使用。不能用临时 session id 伪造 Figma 文件链接。
